## 便宜 VPS 到底应该看什么

很多低价 VPS 对比文章会直接按月费排序，但这只能解决“第一眼多少钱”，不能解决“长期用起来多少钱”。近期关于 cheap VPS 的对比文章反复提到几个容易被忽略的变量，包括续费、带宽/流量限制、存储类型以及共享或独享资源等。

对于 DMIT，最重要的变量其实更集中：**地域 + 网络系列 + 硬件平台**。

DMIT 目前公开三个网络系列：

* **Premium Network**：使用包括中国电信 CN2 GIA 在内的优化路径，目标是降低中国大陆方向的延迟和丢包。
* **Eyeball Network**：在成本和中国访问体验之间做折中，通过 CMIN2/CMI 等线路改善中国住宅用户访问。
* **Tier 1 Network**：不做专门的中国大陆路由优化，官方把它定位为成本更低的通用网络。

这也是为什么同一个“1 vCore、1GB RAM”级别，价格可能差很多。

## 真正追求低价，DMIT 哪条路线更有意义

### Tier 1：预算优先

Tier 1 是 DMIT 自己定义的成本效率路线，不针对中国大陆做专项路由优化。官方建议的用途包括备份、归档、CI/CD、DevOps、跨亚太与美洲的中转节点，以及对成本敏感的通用计算。

它最吸引人的地方就是价格。

HKG.AS3.T1.TINY 和 TYO.AS3.T1.TINY 都是 **$6.90/月**。STARTER 则是 **$12.90/月**。对监控节点、个人实验环境、简单脚本、低流量 API、跳板机这类工作来说，这个价格已经足够低。

但如果你买 VPS 的核心目的就是让中国大陆用户访问网站，那么 Tier 1 的低价就不能单独作为决定因素。

### Premium：多花一点钱换路由

DMIT 的 Premium Network 明确使用 CN2 GIA 等优化网络。官方当前对不同机房给出了参考延迟数据，例如香港到深圳约 15ms 的参考值，东京到中国大陆则约 28ms；官方同时提醒，真实延迟会受接入网络、路由和时间影响。

这类数据适合用来理解网络定位，不适合当成你实际服务器的固定 ping 值。

对“便宜 VPS”搜索用户来说，LAX AS3 Premium TINY 的 **$10.90/月** 是一个很有代表性的分界点：它比最低价 Tier 1 贵，但拿到 2GB RAM，而且网络定位明显不同。LAX AS3 Premium 也提供 Pocket 和 STARTER，更高档位价格继续上升。

如果网站受众主要在中国大陆，而且网络质量比最低月费重要，这类产品比一味追求 $6.90 更符合实际需求。

### Eyeball：成本和中国访问之间的折中

Eyeball 并不是 Premium 的便宜复制品。DMIT 官方把它定位成“成本与覆盖范围之间的平衡”，使用 CMIN2/CMI 等中国运营商相关路径，但不提供 Premium 同等级别的路由保证。

香港当前公开的 AS3 Eyeball 产品包括 TINYv2、STARTERv2、MINIv2、MICROv2，以及更高规格的 MEDIUMv2、LARGEv2、GIANTv2。当前公开价格从 **$29.90/月** 起。

因此，Eyeball 更适合“希望中国用户访问别太差，但又不准备直接买 Premium”的场景。它不是最低价方案，也不是最贵方案，定位非常明确。

**AS3** 基于 AMD EPYC 7003 系列，也就是 Zen 3；**AN4** 基于 AMD EPYC 9004 系列，也就是 Zen 4；**AN5** 则是 AMD EPYC 9005 系列，对应 Zen 5。官网将 AS3 定位为价格更友好的平台，AN4 是均衡型平台，AN5 则更强调计算性能。

因此，不要简单拿“套餐名字一样”来判断价格。

比如 LAX 的 Premium 中，AS3 TINY 是 $10.90/月；同一区域的 AN5 Premium 则从 MINI 规格开始，当前公开价为 $79.90/月，并一路上升到 GIANT $1009.90/月。官方页面同时显示，AN4 Premium 的对应产品目前部分缺货。

这类差距非常大，也说明一个问题：**DMIT 的低价方案主要集中在特定硬件和网络组合，不是整个平台都走“便宜路线”。**

## 流量应该怎么算

看 VPS 价格时，流量是最容易被忽略的维度之一。

LAX AS3 Premium TINY 是 1000GB/月，Pocket 是 1500GB，STARTER 是 3000GB；继续往上，LAX Tier 1 AN5 V2C2G 就已经给到 5000GB Max，V2C4G 为 10000GB Max。

这里尤其要注意 **Max (IN, OUT)** 这样的标记。它和传统 VPS 页面里单纯写“每月 X GB 流量”的表达并不完全一样。不要看到一个超大的 TB 数字就直接理解为“任何方向都可以无条件跑满”。

此外，端口标称值也不是保证的实际吞吐。对于 VPS，CPU、虚拟化、目的地线路以及跨境网络状况都会影响最终速度。DMIT 的官方页面也强调带宽数字在理想条件下代表最大聚合容量，实际运行会受网络条件和运营调整影响。

## 退款规则值得认真看

便宜 VPS 最大的问题之一，是买下来之后才发现不合适。

DMIT 当前条款规定，新订单在购买不超过 **3 天**、同时虚拟机使用流量不超过 **30GB** 的情况下，可以申请全额退款，但会扣除支付网关产生的交易费用。30 天内的新订单，在满足条件时还存在部分退款机制。

同时，续费订单成功支付后属于不可退款范围；使用现有账户余额支付、充值账户余额等场景也有不同退款限制。网络质量不满意、IP 地理位置问题、遭遇 DDoS 等情况同样被列入不可退款情形。

这意味着低价 VPS 最合理的买法，反而不是一次买很长时间，而是先用月付把真实线路、IP、业务兼容性跑通。

## SLA、备份和价格变化也不能忽略

DMIT 当前服务条款写明，现阶段能够提供的 SLA 为 **99%**；如果低于不同门槛，会对应不同额度的补偿。与此同时，条款也明确说明价格和套餐资源可以调整，用户应该主动查看官网的最新计划和价格。

另一个容易被忽略的点是：DMIT 的条款明确写着，除非另有约定，官方不会把你的网站备份作为服务的一部分。因此，生产环境不要把“VPS 提供商有快照/备份功能”理解成“我的数据已经有人替我备份好了”。

当前云实例页面确实列出了 **Automated Backups、Instant Snapshots 和 SSH Key Authentication** 等能力，但这些能力和具体服务、账户配置仍应以购买页面实际可选项为准。

## 便宜 VPS 的几个常见坑，DMIT 也一样

**第一，不能只看首月价格。**

DMIT 当前很多产品本身就是长期月付价格，所以比“首期促销、后面续费翻倍”的营销模式更容易计算。但价格随时间仍可能变化，官方条款也保留了调整价格和资源的权利。

**第二，不能只看 vCore。**

1 vCore + 1GB 的机器和 2 vCore + 4GB 的机器，体验不会只是“多一倍”。内存、磁盘容量、流量以及具体 CPU 平台都会影响实际使用。

**第三，不能把 1Gbps、4Gbps、10Gbps 当成你的实际下载速度。**

这些数字首先是接口或峰值能力。真实速度还受 CPU、磁盘、虚拟化和远端线路限制。DMIT 当前官方材料已经明确提醒这一点。

**第四，不能把“有货”当成永久库存。**

DMIT 的某些热门 Premium 组合当前直接显示 Out of Stock，而同系列其他硬件或网络可能同时可以购买。
